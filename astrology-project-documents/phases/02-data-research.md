## 📂 سند فرعی ۲: تحقیق نجومی، جمع‌آوری Ephemeris و تعیین مجوزها

- **شناسه و اتصال:** AST-P02؛ [سند مادر](../00-master.md)، فاز ۲؛ پیش‌نیاز: دامنه مصوب فاز ۱.
- **مسئول و پذیرنده:** متخصص ودیک و مالک داده؛ معمار و مالک محصول پذیرنده.
- **اهداف فاز:** انتخاب منابع محاسبات، تنظیمات نجومی، محدوده تاریخی و روش اعتبارسنجی.
- **نیازمندی‌ها:** مستند Swiss Ephemeris، منابع مستقل نجومی، IANA tzdb، داده شهرها و بررسی شرایط استفاده هر منبع.
- **لیست تسک‌های اجرایی (To-Do):**
  - [ ] **P02-T01:** مقایسه موتور محلی و API بیرونی از نظر دقت، دامنه تاریخ، قابلیت بازتولید و هزینه.
  - [ ] **P02-T02:** ثبت مجوز موتور، Wrapper، فایل‌های Ephemeris، داده مکان، فونت و متون؛ تعیین مدل استفاده پیش از انتشار.
  - [ ] **P02-T03:** تثبیت زودیاک، لاهیری، Whole Sign، حالت زمین‌مرکزی و گره حقیقی/میانگین؛ تعیین معنای هر خروجی.
  - [ ] **P02-T04:** تهیه فایل‌های Ephemeris برای بازه مصوب؛ ثبت منشأ، نسخه، Checksum و روش به‌روزرسانی.
  - [ ] **P02-T05:** تعریف قرارداد UTC/UT1/TT، مدل ΔT، واحد درجات و مختصات؛ ثبت محدودیت دقت تاریخی.
  - [ ] **P02-T06:** ساخت حداقل ۱۰۰ نمونه مرجع شامل مرز برج، داشا، DST و عرض بالا؛ تعیین تحمل خطا برای هر مقایسه.
- **خروجی نهایی (Deliverable):** کاتالوگ منابع و مجوزها، بسته داده نسخه‌دار، ADR تنظیمات و مجموعه مرجع محاسبات.
- **معیار پذیرش:** استفاده از تمام وابستگی‌ها تعیین تکلیف؛ دامنه پشتیبانی و تحمل خطا ثبت؛ نمونه‌ها توسط متخصص و QA بازبینی.
- **مبنای منبع:** Swiss Ephemeris دارای مسیر AGPL و Professional است؛ انتخاب باید پیش از توزیع یا فعال‌سازی خدمت عمومی انجام شود. [مستند رسمی](https://www.astro.com/swisseph/swephprg.htm)
