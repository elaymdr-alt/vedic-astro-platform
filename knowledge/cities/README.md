Cities: GeoNames `cities15000` (https://www.geonames.org), licensed CC BY 4.0.
`cities.json.gz` is a compact extract: n=ASCII name, f=Persian-script names, c=country,
lat/lon, tz=IANA zone, p=population. Rebuild by downloading
https://download.geonames.org/export/dump/cities15000.zip and extracting those columns.
